# PWA 圖示與靜態資源目錄

此資料夾用於存放前端靜態資源（如 PWA 圖示、Favicon 等）。

請將生成好的圖示檔案放置於此目錄下，並確保檔名與 `vite.config.js` 及 `index.html` 中的設定一致：
- `pwa-192x192.png` (192x192 像素)
- `pwa-512x512.png` (512x512 像素)
- `apple-touch-icon.png` (180x180 像素)
